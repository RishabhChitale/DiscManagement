# v0.4 CLIP image understanding

Date: 2026-10-20 · Status: latest, optional in the demo

## Changes
- **CLIP embeddings:** the "Image understanding" menu has a CLIP option. It runs `clip-vit-base-patch32` in the browser through transformers.js (about 90 MB, downloaded once and cached by the browser). Each image becomes a 512-number vector that captures what is *in* the picture, not just its colours.
- **Zero-shot labels for uploads:** an uploaded image is compared with 32 text prompts ("pixel art", "a book cover", "a fantasy map", "a photograph of food" …) and the best matches are shown with probabilities. No training, no tags needed.
- **Embedding cache:** catalog vectors are stored 8-bit quantised in `localStorage`, so the second visit is instant. The first run embeds 240 images in about 2 minutes.
- Nothing is uploaded; all inference runs on the device.

## Measured
Same simulated users and personas as before. Averaged over personas:

| Features | Version | Avg precision | Last-round precision | Coverage | Redundancy |
|---|---|---|---|---|---|
| Basic | v0.1 | 75% | 55% | 74% | 0.47 |
| Basic | v0.3 | 73% | 62% | 88% | 0.33 |
| CLIP | v0.1 | 94% | 91% | 72% | 0.46 |
| CLIP | v0.2 | 86% | 85% | 81% | 0.30 |
| CLIP | v0.3 | 87% | 85% | 75% | 0.34 |

- Switching to CLIP is worth far more than any algorithm change so far: last-round precision for v0.1 jumps from 55% to 91%.
- With good embeddings, diversity and exploration now cost precision (v0.1 94% vs v0.3 87%) without fixing coverage for multi-interest users (CLIP v0.1 coverage on those personas was 38 to 53%).

## Caveats
- The catalog is synthetic artwork with four visual styles, so it is an easy test for CLIP. Real photos will be messier.
- Simulated users are simple (they like a fixed set and save 70% of what they see). Treat the numbers as a regression check, not proof of real-world quality.
- The "Predicted tags" for an upload still come from nearest-neighbour voting over the demo catalog, so they look odd for images unlike it (a sunset sketch got "games"). The CLIP labels are the better description.
- Diversity and exploration weights were tuned on Basic features and have not been re-tuned for CLIP.
