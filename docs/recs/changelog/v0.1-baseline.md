# v0.1 Baseline: one taste vector

Date: 2026-10-20 · Status: superseded by v0.2

## What it is
The simplest recommender that works with no metadata and no model downloads.

- **Image understanding (Basic):** each image is drawn to a 64×64 canvas and measured: 12-bin hue histogram, saturation, brightness, brightness spread, horizontal and vertical edge density, "flatness", a 3×3 brightness grid and aspect ratio (28 numbers).
- **Tags:** the creator's category and two theme tags, turned into a one-hot vector and blended in at 0.7 weight.
- **Index:** features are centred and z-scored across the catalog so similarity measures what is *different* about an image, then each item becomes one unit-length vector.
- **Taste profile:** a single vector, the weighted sum of saved items (save = 2, view = 0.3), with hidden items subtracted (Rocchio). Events older than 14 days count half as much.
- **Ranking:** cosine similarity to the taste vector, plus a small popularity prior (smoothed save rate, 0.15 weight). Saved and hidden items are removed, viewed items are demoted.
- **Reasons:** each pin says which saved pin it is most like.
- **Auto-categorising an upload:** the nearest catalog items vote on tags (k-nearest-neighbours on the visual part only).

## What shipped alongside
- `docs/recs.html`, a "For you" feed with save / not-interested buttons, a detail view with "More like this", a taste panel and an upload analyser.
- `docs/recs-eval.html`, an offline evaluation using simulated users.
- Events are stored in the browser only (`localStorage`). Nothing is uploaded.

## Measured (simulated users)
See the table in v0.3. Averaged over four personas, v0.1 scored 75% precision (mean of 5 rounds) but only 74% coverage and the most redundant feeds (0.47).

## Lessons
- With a 120-item catalog every persona looked close to random. The cause was running out of relevant items, because saved items are removed from the feed. Catalog raised to 240 for evaluation.
- Cosine similarity on hand-made image features works for style, but is weak on "what is this a picture of".

## Known weaknesses
- One average vector blurs together people with two different tastes.
- Feeds can become near-duplicates of the same thing.
- No exploration, and no boost for brand-new uploads.
